# Notes

Dated, attributed notes that never reach a paper: decisions and why, what
was tried, open questions. One Markdown file per topic or per work
(`<bibkey>.md`). `dead-ends.md` is the append-only log that
`omnibus-node dead-end` and the `record_dead_end` MCP tool write to.

Every note starts with a line of the form:

    2026-09-13 · 0000-0003-1190-1122 · <project or bibkey>

Notes are served at tier `notes` and above.
